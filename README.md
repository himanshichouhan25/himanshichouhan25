# 🌟 Featured Projects

## ✈️ AI Travel Planner
> **A full-stack agentic AI app that turns a trip idea into a complete, personalized itinerary using a 3-agent CrewAI pipeline.**

### 🚀 Features
- 🧭 Planner Agent — builds the day-by-day itinerary
- 💰 Budget Agent — checks and optimizes spending
- 🔍 Reflection Agent — reviews and improves the final plan
- 🔐 JWT Authentication (register/login/me)
- 🗂️ Trip history + preferences management
- ⚡ Groq (Llama-3.3-70B) powered reasoning

### 🛠 Tech Stack
`React` `Vite` `Tailwind CSS` `Shadcn UI` `FastAPI` `SQLAlchemy` `SQLite` `JWT` `CrewAI` `Groq`

## 🔍 CodeAudit
> **An AI-powered multi-agent platform that reviews code automatically — quality, bugs, performance, and security checked by four specialized agents.**

### 🚀 Features
- 🤖 Multi-Agent Code Review (CrewAI): Quality, Bug, Performance, Security agents
- 🏗️ FastAPI backend + Streamlit frontend
- ⚡ Groq LLM-powered analysis
- 🗂️ Review history persisted in SQLite

### 🛠 Tech Stack
`Python` `FastAPI` `Streamlit` `CrewAI` `Groq` `SQLite`

## 📚 Study Buddy Agent
> **An AI-powered CS study companion that explains concepts clearly, gives real examples, and ends every answer with a follow-up question to keep you thinking.**

### 🚀 Features
- 🤖 Explains algorithms, data structures, networking, system design
- 💡 Example-driven, code-snippet answers
- 🗂️ Multi-session chat history in sidebar
- 🌙 Dark/Light mode toggle

### 🛠 Tech Stack
`React` `Vite` `Tailwind CSS` `FastAPI` `Google Gemini 2.0 Flash` `Pydantic v2`
